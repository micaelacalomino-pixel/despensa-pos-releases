    Vendedores

    Cada vendedor tiene su pestaña en Venta con su propio carrito. “Invitado” siempre está disponible para que lo use cualquiera.

    Un lector para cada uno (opcional): programá cada lector para que agregue una letra antes del código (en su manual: “Prefix” / “Agregar prefijo”), por ejemplo A para Ana y B para Juan, y elegí esa letra al lado de su nombre. Al escanear con su lector, la pantalla pasa a su pestaña.

    Pasá cada lector a modo COM escaneando “USB COM” en su manual (para volver: “USB”). Después tocá Asignar lector al lado de cada nombre y escaneá un producto con su lector. En modo COM el lector solo escribe en Despensa POS.

    Ticket e impresora

    Si se cortan las letras de la derecha, bajá los caracteres por línea. Si se cortan las de la izquierda, agregá margen.

    La impresora debe estar instalada en Windows y ser la predeterminada. Ver README → “Impresora de tickets”.

    Balanza con etiqueta

    Para balanzas que imprimen una etiqueta con código de barras que empieza con 2 (Systel, Kretz, Moretti, Dibal…). Cargá cada producto pesable con el mismo número (PLU) que tiene en la balanza como código, por ejemplo 15.

    Datos

    Borra toda la lista de productos (por ejemplo, para importar otra). Las ventas y la caja no se tocan.

    Copia de seguridad

    Guardá una copia en un pendrive o en tu correo al menos una vez por semana.

    Instalación

    Para instalar: en Chrome o Edge, menú ⋮ → “Instalar Despensa POS”.
